# StudyNotesSFU-Updates

Публичный репозиторий обновлений StudyNotesSFU. Исходный код приложения хранится отдельно в приватном репозитории.

- `stable.json` — стабильный канал обновлений для обычных пользователей.
- `test.json` — тестовый канал для предварительной проверки новых сборок.
- APK-файлы будут публиковаться здесь после подписания постоянным release-ключом.

Обычный сценарий: новая версия сначала публикуется в Test, затем после проверки переводится в Stable. При одинаковом package name и подписи Android устанавливает новую версию поверх старой без удаления данных приложения.
